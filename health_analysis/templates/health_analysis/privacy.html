개인정보처리방침

핵심 원칙

SSH는 어떠한 개인정보도 수집하지 않습니다

1. 개인정보의 수집

수집하지 않는 정보
  • 이름, 주민등록번호, 전화번호 등 개인 식별 정보
  • 이메일 주소, 주소 등 연락처 정보
  • IP 주소, MAC 주소 등 기기 식별 정보
  • 쿠키, 세션 정보 등 웹 추적 정보
  • 위치 정보, 접속 로그 등 행동 정보
처리하는 정보
  • 설문 응답: 19개 건강 관련 질문에 대한 익명 응답
  • 처리 방식: 동형암호로 즉시 암호화하여 처리
  • 저장 여부: 일체 저장하지 않음

2. 동형암호 처리 과정

사용자 입력
설문 응답
즉시 암호화
클라이언트에서
서버 처리
암호화 상태로
중요: 서버는 평문 데이터를 절대 보지 못하며, 오직 암호화된 데이터만 처리합니다.

3. 데이터 보안

기술적 보호조치
  • CKKS 동형암호: 데이터를 암호화한 상태에서 연산
  • 클라이언트 키 관리: 복호화 키는 사용자 브라우저에만 존재
  • HTTPS 통신: 모든 데이터 전송 구간 암호화
  • 메모리 내 처리: 서버 디스크에 데이터 저장 안 함
관리적 보호조치
  • 개인정보 처리 직원 없음 (자동화 시스템)
  • 정기적 보안 점검 및 업데이트
  • 외부 침입 방지 시스템 운영

4. 서비스 이용 기록

기록하지 않는 정보
  • 접속 IP 주소
  • 접속 시간
  • 브라우저 정보
  • 운영체제 정보
  • 접속 경로
기록하는 정보
  • 시스템 오류 로그 (개인정보 제외)
  • 서비스 성능 모니터링
  • 익명화된 이용 통계

5. 쿠키 및 추적 기술

쿠키 사용 안 함

SSH는 사용자 추적을 위한 쿠키, 로컬 스토리지, 세션 스토리지 등을 일체 사용하지 않습니다.

단, 다음의 경우에만 임시적으로 브라우저 메모리를 사용합니다:

  • 동형암호 키 생성 및 관리 (페이지 새로고침 시 삭제)
  • 분석 결과 표시 (페이지 이동 시 삭제)

6. 제3자 제공

제3자 제공 절대 없음

수집하는 개인정보가 없으므로, 제3자에게 제공할 정보 자체가 존재하지 않습니다.

7. 개인정보 보호책임자

개인정보를 수집하지 않는 서비스이므로 별도의 개인정보보호책임자를 두지 않습니다.

서비스 관련 문의

기술적 문의사항이나 서비스 개선 제안이 있으시면 GitHub 저장소의 Issues를 통해 연락 주시기 바랍니다.

8. 방침 변경

이 개인정보처리방침은 2025년 1월 1일부터 적용됩니다. 향후 내용이 추가, 삭제 또는 수정되는 경우 변경사항의 시행 7일 전부터 서비스 내 공지사항을 통하여 고지할 것입니다.

  • 최초 제정: 2025년 1월 1일
  • 최종 수정: 2025년 1월 1일
