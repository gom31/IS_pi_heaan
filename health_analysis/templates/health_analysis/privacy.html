Privacy Policy

Core Principle

SSH does not collect any personal information

1. Collection of Personal Information

Information We Do NOT Collect
  • Personal identification information such as names, social security numbers, phone numbers
  • Contact information such as email addresses, physical addresses
  • Device identification information such as IP addresses, MAC addresses
  • Web tracking information such as cookies, session information
  • Behavioral information such as location data, access logs
Information We Process
  • Survey Responses: Anonymous responses to 19 health-related questions
  • Processing Method: Immediately encrypted using homomorphic encryption
  • Storage: Not stored at all

2. Homomorphic Encryption Process

User Input
Survey responses
Immediate Encryption
On client side
Server Processing
In encrypted state
Important: The server never sees plaintext data and only processes encrypted data.

3. Data Security

Technical Safeguards
  • CKKS Homomorphic Encryption: Computation on encrypted data
  • Client-side Key Management: Decryption keys exist only in user's browser
  • HTTPS Communication: All data transmission encrypted
  • In-memory Processing: No data stored on server disk
Administrative Safeguards
  • No personal information processing staff (automated system)
  • Regular security checks and updates
  • External intrusion prevention system operation

4. Service Usage Records

Information We Do NOT Record
  • Access IP addresses
  • Access times
  • Browser information
  • Operating system information
  • Access paths
Information We Record
  • System error logs (excluding personal information)
  • Service performance monitoring
  • Anonymized usage statistics

5. Cookies and Tracking Technologies

No Cookie Usage

SSH does not use any cookies, local storage, session storage, or other user tracking technologies.

However, browser memory is used temporarily only in the following cases:

  • Homomorphic encryption key generation and management (deleted on page refresh)
  • Analysis result display (deleted on page navigation)

6. Third-party Disclosure

Absolutely No Third-party Disclosure

Since we do not collect personal information, there is no information to provide to third parties.

7. Privacy Protection Officer

Since this service does not collect personal information, we do not designate a separate privacy protection officer.

Service-related Inquiries

If you have technical questions or service improvement suggestions, please contact us through Issues in our GitHub repository.

8. Policy Changes

This privacy policy is effective from January 1, 2025. If content is added, deleted, or modified in the future, we will notify users through service announcements 7 days before the changes take effect.
