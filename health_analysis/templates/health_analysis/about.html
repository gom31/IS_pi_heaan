SSH - SecureSexHealth

🎯 Service Purpose

SSH is an innovative service that provides personalized risk assessment while ensuring complete anonymity for the sensitive topic of sexual health. You can objectively understand your health status without concerns about social prejudice or personal information exposure.

🔒 Homomorphic Encryption Technology

Homomorphic Encryption is an innovative encryption technology that allows computations to be performed on encrypted data without decrypting it.

1. Encrypted Transmission
User data is immediately encrypted and transmitted to the server
2. Encrypted Computation
AI model calculates risk assessment on encrypted data
3. Result Decryption
Only the user can decrypt and view the final results

🤖 AI Model Information

SSH uses a logistic regression model trained on HIV/AIDS related datasets.

  • Input Features: 19 sexual health related factors
  • Model Type: Logistic Regression
  • Training Data: Anonymized public HIV/AIDS dataset
  • Prediction Target: HIV/AIDS infection risk probability

🛡️ Privacy Protection

Guaranteed Protections
  • All data is immediately encrypted on the client side
  • Server only processes encrypted data
  • No collection of personally identifiable information
  • No storage of tracking information like IP addresses or cookies
  • Operates with completely anonymous sessions
Technical Safeguards
  • Uses CKKS homomorphic encryption algorithm
  • Client-side key management
  • HTTPS communication encryption
  • No data storage on server side

⚠️ Important Limitations

Please Read Carefully
  • Reference Only: This assessment is for reference only and is not a medical diagnosis
  • Professional Consultation Required: Accurate diagnosis must be obtained through consultation with medical professionals
  • Educational Purpose: This system was developed for educational and research purposes
  • Not Perfect: AI model predictions may contain errors

🎓 Development Background

This project is an academic research project for developing privacy-preserving applications using homomorphic encryption. We are exploring the practical applicability of homomorphic encryption technology through the sensitive topic of sexual health.
