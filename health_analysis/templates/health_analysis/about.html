SSH - SecureSexHealth

🎯 서비스 목적

SSH는 성적 건강이라는 민감한 주제에 대해 완전한 익명성을 보장하면서 개인 맞춤형 위험도 평가를 제공하는 혁신적인 서비스입니다. 사회적 편견이나 개인정보 노출에 대한 우려 없이 자신의 건강 상태를 객관적으로 파악할 수 있습니다.

🔒 동형암호 기술

동형암호(Homomorphic Encryption)는 데이터를 암호화한 상태에서도 연산을 수행할 수 있는 혁신적인 암호화 기술입니다.

1. 암호화 전송
사용자 데이터가 즉시 암호화되어 서버로 전송
2. 암호화 연산
암호화된 상태에서 AI 모델이 위험도 계산
3. 결과 복호화
사용자만이 최종 결과를 복호화하여 확인

🤖 AI 모델 정보

SSH는 HIV/AIDS 관련 데이터셋을 기반으로 훈련된 로지스틱 회귀 모델을 사용합니다.

  • 입력 특성: 19개의 성적 건강 관련 요인
  • 모델 타입: 로지스틱 회귀 (Logistic Regression)
  • 훈련 데이터: 익명화된 공개 HIV/AIDS 데이터셋
  • 예측 대상: HIV/AIDS 감염 위험도 확률

🛡️ 개인정보 보호

보장되는 사항
  • 모든 데이터는 클라이언트에서 즉시 암호화
  • 서버는 암호화된 데이터만 처리
  • 개인 식별 정보 일체 수집 안 함
  • IP 주소, 쿠키 등 추적 정보 저장 안 함
  • 완전한 익명 세션으로 운영
기술적 보호조치
  • CKKS 동형암호 알고리즘 사용
  • 클라이언트 측 키 관리
  • HTTPS 통신 암호화
  • 서버 측 데이터 미저장
